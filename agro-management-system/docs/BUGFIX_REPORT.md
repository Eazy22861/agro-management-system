# Bugfix Report: SensorService

## Қате түрлері
**Компиляция кестесі** - Синтаксис немесе типтер сәйкестігінің бұзылуы. Компиляция кезіңде анықталады.
**Орындалу уақытында қате (Runtime Exception)** - Бғдарлама жұмыс істеп тұрғанда күтпеген жағдайдан үзілуі. Бағдарлама іске қосқанда.
**Логикалық қате** - Бағдарлама құламайды, бірақ нәтиже қате есетеледі. Тестілеу/шекаралық мәндерде.
